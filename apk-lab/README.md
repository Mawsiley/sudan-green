# APK Lab

ارفع ملف APK ← يُفكّ بـ [Apktool](https://github.com/iBotPeaches/Apktool) ← يحلله DeepSeek ← تعدّل الملفات (يدوياً أو بالذكاء الاصطناعي) ← يُعاد بناؤه ويُوقَّع ويُحمَّل.

## لماذا مكوّنان؟
Netlify يستضيف الصفحات الثابتة والدوال القصيرة فقط (لا Java، مهلة ~10–26 ثانية، حد 6MB للطلب)، وApktool يحتاج Java ووقتاً وملفات كبيرة.
لذلك:
- `web/` ← الواجهة على **Netlify**.
- `server/` ← خادم صغير (Node + Java + Apktool) على أي استضافة Docker (Render / Railway / Fly.io / VPS).

## التشغيل
1. **الخادم**: انشر مجلد `server/` كخدمة Docker (يُبنى من `server/Dockerfile`). متغيرات البيئة:
   - `ACCESS_TOKEN` (موصى به) رمز يحمي الخادم من الاستخدام العام.
   - `ALLOWED_ORIGIN` رابط موقع Netlify، مثل `https://my-site.netlify.app`.
   - `DEEPSEEK_API_KEY` (اختياري) إن لم تدخل المفتاح من الواجهة.
2. **Netlify**: أنشئ موقعاً من المستودع، وBase directory = `apk-lab` (الإعدادات في `netlify.toml`).
3. افتح الموقع، أدخل رابط الخادم ومفتاح DeepSeek ورمز الدخول واضغط «حفظ».
4. ارفع APK ← حلّل ← عدّل ← «بناء وتوقيع APK وتحميله».

## ملاحظات
- الملف الناتج موقّع بمفتاح debug (عبر uber-apk-signer)؛ لا يمكن تثبيته فوق نسخة موقّعة بمفتاح آخر، ثم يجب حذف الأصلية أولاً.
- التطبيقات المحمية أو المشفّرة قد تفشل في الفك/البناء.
- الجلسات تُحذف تلقائياً بعد ساعة. استخدم الأداة على تطبيقات تملكها أو مصرّح لك بتعديلها.
